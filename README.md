Cybersecurity Services Landing Page

A fully responsive, interactive landing page built for cybersecurity freelance services and consultation requests.

  Features
Interactive UI/UX: Smooth animations, hover effects, and responsive modal popups for service inquiries.
Direct Lead Generation: Integrated with Formspree to deliver client requests straight to email without a heavy backend.
Basic Hardening: Client-side input sanitization to mitigate XSS (Cross-Site Scripting) vulnerabilities on form submission.
  Responsive Design: Optimized for desktop and mobile screen sizes.

Tech Stack
-Frontend: HTML5, CSS3, Modern JavaScript (ES6+)
Integration: Formspree API
Deployment: GitHub Pages
